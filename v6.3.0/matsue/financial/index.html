このレポートについて

市のお金の流れ（歳入・歳出）と、市が持っている資産・背負っている負債を、公式の決算資料をもとに市民が読める形に整理したレポートです。専門用語はできるだけ避け、必要なものには説明を添えています。

確認できること
収支 1年間のお金の入り（歳入）と出（歳出）の内訳。何から得て、何に使ったか。 市が持っているもの・背負っているもの 基金や公共施設などの資産と、市債などの負債。返済の負担度も。 経年推移 この数年で財政がどう変わったか。総額・内訳・基金・市債の推移。

データの作り方

公式の決算資料（歳入歳出決算書・財政状況資料集など）を読み取り、款・目的別・性質別などの区分で構造化・集計しています。金額は原則として億円単位に丸めて表示しています。

分析は Claude Code のセッション内のルールベース処理で行っており、生成 AI の外部 API や機械 OCR は使用していません。

中立性

本レポートはデータの分類・集計の結果です。財政運営の良し悪しといった評価・判断は含みません。増減や比率は事実として示し、解釈は読み手に委ねます。
