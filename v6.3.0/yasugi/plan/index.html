このレポートについて

市の最上位計画である総合計画が、どんな体制で作られ、議会での議論や予算配分とどう関わっているかを、公式資料をもとに市民が読める形に整理したレポートです。示すのはデータの集計・対比であり、計画への評価・判断は含みません。

  • 対象計画: 第2次安来市総合計画
  • 計画期間: H28〜R07
確認できること
計画のしくみ 計画を策定・点検する審議会の委員構成と、市民の関わり方。 議会と計画 計画が掲げるテーマと、議会で議論されるテーマの対比。 予算と計画 計画が掲げるテーマと、実際の歳出配分の対比。
出典・データの作り方・中立性

出典（一次資料）

数値はすべて市が公表する公式資料に基づきます。原典は以下でご確認いただけます。

  • 総合計画 本体計画: 第2次安来市総合計画 本体計画（前期・後期 基本計画） （対象期間: H28〜R07） ［PDF］ — 公開元: 安来市 （本体PDFは ToUnicode CMap 欠落で漢字化けするため、計画構造（7目標×98取組の名称・階層）は手動転記YAML（data/manual/安来市/総合計画構造.yaml）、目標指標の数値は本体PDFから pdfplumber で自動抽出するハイブリッドで整備）
  • 計画構造（手動転記）: data/manual/安来市/総合計画構造.yaml ［YAML］ — 公開元: 安来市 （本体PDFの漢字化けを回避するため、5理念→7目標→98取組の階層・名称を人手で転記した手動マスター（取得元: download_yasugi_plan.py））

対比には、議会データ（議会レポートと同一ソース）・財政データ（財政レポートと同一ソース）も利用しています。

データの公開元: 安来市 第2次総合計画

データの作り方

総合計画の施策体系・審議会資料を読み取り、施策をテーマ分類したうえで、議会質疑・歳出の各テーマシェアと対比しています。策定年度を境に策定前後の変化を算出します。

分析は Claude Code のセッション内のルールベース処理で行っており、生成 AI の外部 API や機械 OCR は使用していません。

中立性

本レポートはデータの分類・対比の結果です。計画や行政運営の良し悪しといった評価・判断は含みません。シェアの差（力点のずれ）は事実として示し、解釈は読み手に委ねます。
